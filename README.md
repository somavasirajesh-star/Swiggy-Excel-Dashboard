# 🍔 Swiggy Sales & Business Analytics Dashboard

## 📊 Project Overview

This project is an **interactive Swiggy Sales & Business Analytics Dashboard built using Microsoft Excel**.

The objective of this project was to transform raw Swiggy order data into an interactive business dashboard that helps analyse **sales performance, customer behaviour, order trends, product performance and key business KPIs**.

The project follows an end-to-end analytics workflow:

**Raw Data → Data Cleaning → Data Analysis → Pivot Tables → Dashboard → Business Insights**

---

## 🎯 Business Objective

The main objective of this project was to answer important business questions such as:

* How are sales performing over time?
* Which products/categories generate the highest sales?
* Which customer segments contribute the most revenue?
* What are the major order trends?
* Which areas or categories require further investigation?
* What business insights can be derived from the available data?

## 📈 Dashboard Features

The dashboard provides an interactive view of business performance through:

* 📌 Key Performance Indicators (KPIs)
* 📈 Sales trend analysis
* 🛍️ Product/category performance
* 👥 Customer analysis
* 📦 Order analysis
* 📊 Interactive Pivot Charts
* 🎛️ Slicers for dynamic filtering
* 🔎 Business performance comparisons

Users can interact with the dashboard using slicers and filters to analyse different parts of the business.

---

## 🔍 Analysis Performed

### 1. Sales Analysis

Analysed sales performance to understand revenue trends and identify high-performing areas.

### 2. Product & Category Analysis

Compared products and categories to identify major contributors to overall sales.

### 3. Customer Analysis

Analysed customer-related patterns to understand purchasing behaviour and identify important customer groups.

### 4. Order Analysis

Examined order-level information to understand order trends and overall business activity.

### 5. Business KPI Analysis

Created and monitored important metrics to provide a quick overview of business performance.
